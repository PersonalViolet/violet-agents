## 问题复现

```python

from violet_agents import VioletAgentsLLM

    name="helloAgent",
    llm=VioletAgentsLLM(provider="deepseek"),
    system_prompt="你是一个简单的助手，直接回答用户的问题，不进行复杂的思考和计划。"

response = agent.run("你好，1 + 1 等于多少？")
```

## 追踪报错

### 先看报错最后一行，明确错误类型和原因

```
ImportError: cannot import name 'Agent' from partially initialized module 'violet_agents.core.agent' (most likely due to a circular import) (D:\programming\Python\test_violet_agent\.venv\lib\site-packages\violet_agents\core\agent.py)
```

- **错误类型**：`ImportError` – 导入失败。
- **具体原因**：无法从 `violet_agents.core.agent` 中导入 `Agent`，而且模块处于“部分初始化”状态，**很可能是因为循环导入（circular import）**。

### 从下往上读，定位循环链条

Traceback 是从**最底层（错误发生点）**向上（调用入口）排列的，**最后一行是错误本身**，而**上面每一行都显示了导入过程中的一环**。

```
File "...\search_tools_tool.py", line 7, in <module>
    from ...core.agent import Agent, SubAgent
```

- 这里试图从 `core.agent` 导入 `Agent`，是**直接触发错误的地方**。

再往上看，是谁导入了 `search_tools_tool.py`？

```
File "...\tools\builtin\__init__.py", line 4, in <module>
    from .search_tools_tool import SearchToolsTool
```

- `builtin/__init__.py` 导入了 `search_tools_tool`。

继续：

```
File "...\tools\__init__.py", line 3, in <module>
    from .builtin import WeatherTool, SkillsTool, SearchToolsTool, TerminalTool
```

- `tools/__init__.py` 导入了 `builtin` 包。

再往上：

```
File "...\core\agent.py", line 10, in <module>
    from ..tools.registry import ToolRegistry
```

- 我们发现`core/agent.py` 里导入了 `tools.registry`，而 `tools` 包又导入了 `builtin`包，进而导入了 `search_tools_tool`，而它又反过来导入 `core.agent` —— **这就形成了循环**。这种情况是间接循环导入，由这几个`__init__.py`把路铺成了闭环，**简单说，就是`search_tools_tool.py`在执行`from ...core.agent import Agent, SubAgent`时，回头找还没定义完的`core/agent.py`**。

## 解决方法

**`core/agent.py`**

- 将 `from ..tools.registry import ToolRegistry` 从顶层导入移入 `TYPE_CHECKING` 块
- `__init__` 中改用懒加载：`from ..tools.registry import ToolRegistry as _ToolRegistry`
- 消除了 `core.agent` ↔ `tools.builtin.search_tools_tool` 之间的潜在循环导入
